# ResQOne
ResQOne Citizen Frontend — A responsive React application for emergency reporting, incident tracking, and citizen access to emergency response services.

## Citizen Frontend Module
This repository contains the Citizen Frontend for the ResQOne emergency management platform.

### Tech Stack
- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS
- **Routing:** React Router v6
- **Icons:** Lucide React

### Getting Started

#### Prerequisites
- Node.js (v18+ or v22 LTS recommended)
- npm (v9+ or v10+)

#### Installation
```bash
npm install
```

#### Development
```bash
npm run dev
```
The application will start locally at `http://localhost:3000`.

#### Production Build
```bash
npm run build
```
The compiled output will be generated in the `dist/` directory.
